## 1. /tury-v-gruziyu/ — Категорийный хаб

### SERP Consensus
Запрос «туры в Грузию 2026» — 100% SERP занят крупными туроператорами и агрегаторами (Coral, Level.travel, Tez-Tour, Intourist, Travelata, YouTravel.me). Тип страниц: **каталог с живым инвентарём и онлайн-бронированием** (даты, цены, фильтры, checkout). Confidence: 95%.

### Page-Type Mismatch
**CRITICAL**

Страница оформлена как **информационная статья** (article-hero, article-wrap, article-body, TOC, warn-box). Структура: аналитика рынка → сравнительная таблица форматов → разбор пакетного vs авторского тура. Google видит редакционный контент; SERP требует транзакционный каталог.

Конкуренты дают: живые даты, фильтр по бюджету/длительности, checkout/оплата. Страница даёт: текст с grid-миниатюрами туров внизу без цен в лари и без возможности сразу выбрать дату.

### User Story (сигнал: SERP = 100% коммерция)
- «Хочу купить готовый тур в Грузию с перелётом из России — сравнить цены и выбрать оператора» (Decision, не удовлетворён)
- «Хочу понять разницу между форматами, потом выбрать» (Consideration — страница закрывает, но до покупки путь длинный)
- «Релокант: ищу экскурсии уже из Тбилиси, не пакет» (Awareness — страница избыточна)

## 2. /tury-v-gruziyu-iz-moskvy/ — Гео-лендинг

### SERP Consensus
Запрос «тур из Москвы в Грузию 2026» — все 7 результатов: туроператоры и агрегаторы с перелётом. Тип: **страница категории с авиабилетом + проживание + checkout**. Confidence: 90%.

### Page-Type Mismatch
**HIGH**

Страница — гибрид (hub-hero + информационные секции + таблица рейсов + карточки туров). Ближе к нужному формату чем /tury-v-gruziyu/, но есть критический контекстный мismatch: страница предлагает **экскурсии от Тимура из Тбилиси**, тогда как пользователь ищет **пакетный перелёт из Москвы**. Это разные продукты.

Пользователь ищет: купить авиабилет + отель + трансфер одним пакетом. Страница предлагает: приехать в Тбилиси и потом купить экскурсии от ₾98.

### User Story
- «Еду из Москвы, хочу всё купить сразу — перелёт, отель, экскурсии» (Decision — страница не закрывает, нет checkout)
- «Считаю бюджет поездки из Москвы» (Consideration — страница закрывает хорошо: таблица рейсов, цены)
- «Уже купил билет, ищу гида» (Awareness нижнего намерения — Sakhva подходит)

### Приоритетные фиксы
1. **Явный disclaimer вверху**: «Авиабилеты — через Aviasales/Skyscanner. Я встречу вас в Тбилиси и проведу по Грузии»
2. **Партнёрский блок** с кнопкой «Найти билеты Москва → Тбилиси» (Aviasales deeplink) — снижает bounce
3. **Добавить раздел «Маршруты на 5/7/10 дней»** с реальными днями программы (ключевое различие от пакетного тура)
4. **Отзыв от московского клиента** в hero-зоне — e-e-a-t сигнал для этой геоаудитории

**MEDIUM**

## 5. /en/ — EN главная

### SERP Consensus
Запрос «Tbilisi tour guide private tours Georgia 2026» — ToursByLocals, TripAdvisor (Private Tour Georgia), Viator, GoWithGuide. Тип: **профильная страница гида или listing тур-операторов** с фото гида, отзывами, списком туров, онлайн-бронированием. Confidence: 85%.

### Page-Type Mismatch
**HIGH**

EN главная — полноценный лендинг (hero-видео, туры, отзывы, FAQ). Сам по себе правильный тип. Проблема: **ранжируется по generic «Georgia tours» а не по «Tbilisi private tour guide»**. Разница: generic — 380+ маршрутов на агрегаторе; guide-specific — один человек, его фото, credentials, отзывы.

Конкуренты в EN-SERP выигрывают за счёт:
- TripAdvisor: 500+ отзывов, агрегейт рейтинг
- ToursByLocals: verified badge, license, photo
- GoWithGuide: instant booking, calendar

EN главная пытается конкурировать с агрегаторами всем сразу, вместо того чтобы ранжироваться на нишевый «private guide» интент.

### User Story

## Кросс-страничные системные проблемы

1. **Нет AggregateRating schema ни на одной странице тура** — прямая потеря review-snippet в SERP. Все конкуренты (Viator, Sputnik8) имеют звёзды в выдаче.
2. **FAB-кнопка (мобильный CTA)** работает глобально — но на /tury-v-gruziyu/ первые 2 экрана не имеют ни одного CTA выше сгиба. FAB появляется только после скролла.
3. **Цены в лари без рублей** — на страницах для RU-аудитории. Релоканты знают лари, туристы из России — нет. Нужен dual-currency display.
4. **modified_time застряли** на мае-июне — Google даёт freshness-boost свежему контенту. Обновлять при любом изменении.
5. **EN-страницы не оптимизированы под guide-specific intent** — конкурируют с агрегаторами всем сайтом вместо нишевого «hire a guide» фокуса.

## Ограничения анализа

- SERP-анализ проводился без Ahrefs/SEMrush данных о реальных позициях — приоритеты основаны на SERP-snapshot и структуре страниц

- Yandex SERP не анализировался — для RU-аудитории это отдельный приоритет
- TripAdvisor-профиль Тимура не проверен — неизвестно наличие/отсутствие верифицированного аккаунта

# PRD: Sakhva Travel — UX/UI Redesign
## Based on: Full UX audit + Google Stitch reference design

### Project Overview
Redesign sakhva-travel.com to improve conversion, trust, and visual quality.
Stack: Static HTML + Vercel Serverless. Main file: index.html (2086 lines).
Reference design: Stitch-generated HTML at /tmp/sakhva-stitch-homepage.html
Current colors to replace: blue #1A56DB → green #2d6a4f
Fonts to add: Montserrat (headlines), keep Inter/Raleway (body)

---

## PHASE 1: Header Redesign (CRITICAL)

### 1.1 Remove "ОПЛАТИТЬ" button from nav
- The payment CTA in the header creates anxiety before user has chosen a tour
- Remove .nav-btn element that triggers #pm-modal from the nav
- Keep payment modal functionality, just move trigger to tour pages only

### 1.2 Simplify navigation
- Current: ТУРЫ | БЛОГ | ВСЕ ТУРЫ | КАК БРОНИРОВАТЬ | ГИД | ОТЗЫВЫ | FAQ + phone + pay button + RU/EN = 10+ elements
- Target: Туры | Блог | О гиде | Отзывы + phone number + "Выбрать тур" CTA + RU/EN
- Remove duplicate "ВСЕ ТУРЫ" (same as "ТУРЫ")
- Remove "КАК БРОНИРОВАТЬ" from main nav (move to FAQ section)

### 1.3 Replace all blue CTAs with green
- Find all instances of #1A56DB and replace with #2d6a4f
- Update hover states proportionally
- Update gradient on nav-btn to green tones

### 1.4 Add mobile sticky bottom bar
- Fixed bar at bottom of mobile viewport (below 768px)
- Two buttons: "Выбрать тур" (green, left) + "WhatsApp" (white/outline, right)
- Hide on desktop
- z-index above content, below modals

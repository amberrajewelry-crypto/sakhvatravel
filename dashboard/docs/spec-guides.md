# Spec: Гиды, регламент и расчёты в дашборде

## Objective
Полина (менеджер) ведёт брони в дашборде без Владимира: видит список гидов,
назначает гида из списка, получает подсказки по регламенту прямо на рабочем
столе и закрывает расчёт с гидом после тура. Владимир видит сводку «сколько
должны каждому гиду за месяц».

Пользователи: Полина (ежедневно), Владимир (контроль/выплаты).

## Допущения (поправь, если не так)
1. Источник истины — Airtable. Таблица «Гиды» (tbloTqD4pI8eqR8FX) уже есть, дополняем поля, не создаём новую.
2. В бронях поле «Гид» остаётся текстом (без миграции на link-поле): дашборд даёт выбор только из таблицы «Гиды», а ручной ввод убираем. Старые значения («Саба », «Сенсей») нормализуем один раз скриптом.
3. Гонорар гида — отдельное поле в брони «Гонорар гида ₾» (число). «Расходы€» не трогаем (это бензин/еда/билеты).
4. Выплата фиксируется галочкой «Гиду выплачено» в брони. Отдельной таблицы выплат нет — 3–4 гида, хватит.
5. Подтверждение гида — галочка «Гид подтвердил» в брони; ставит Полина после «ок» от гида.
6. «Регламент» — статичный текст внутри дашборда (кнопка «Регламент» в шапке) + автоматические карточки в «Требуют внимания». Текст также лежит в репо `dashboard/docs/reglament.md`.
7. Ставки: у гида в таблице «Ставка ₾/день» по умолчанию; в брони можно переопределить.
8. Права: Полина может править гонорар, но не «Итого» (Сумма) — на UI поле «Итого» остаётся редактируемым как сейчас; ограничение — регламентом, не кодом (дашборд без ролей).

## Изменения в Airtable (ask first — схема)
Таблица «Гиды»: + `Ставка ₾/день` (number), + `Туры` (long text: какие водит), + `Порядок` (number, для сортировки).
Таблица «Бронирования»: + `Гонорар гида ₾` (number), + `Гид подтвердил` (checkbox), + `Гиду выплачено` (checkbox).
Заполнить «Гиды»: Тимур (есть), Саба, Сенсей, Эрик, Шота — телефон/языки/регионы/машина/ставка (данные — от Владимира; пустое = `[ЗАПОЛНИТЬ]`).
Прокси `api/at.js`: разрешить таблицу `tbloTqD4pI8eqR8FX` (GET/PATCH).

## Изменения в дашборде (index.html)
1. **Гид в брони** — `<select>` из таблицы «Гиды» (статус ≠ «неактивен») + пункт «— не назначен —». Водитель — как сейчас.
2. **Блок «Гид» в брони**: гонорар ₾ (предзаполняется ставкой гида при выборе), чекбоксы «Гид подтвердил», «Гиду выплачено», кнопка «Карточка гиду» (уже есть — не дублировать, переиспользовать).
3. **«Требуют внимания»** — новые карточки:
   - «Гид не назначен» — бронь Подтверждена, дата ≥ сегодня, гид пуст.
   - «Гиду не подтверждено» — выезд завтра/сегодня, «Гид подтвердил» = нет.
   - «Закрыть тур» — дата < сегодня, статус Подтверждена (не переведена в Проведена) или Проведена без гонорара.
4. **Кнопка «Гиды»** в шапке → панель: таблица гидов (имя, телефон tap-to-call/WhatsApp, языки, регионы, машина, ставка, статус) + сводка за выбранный месяц: туров, гонорар Σ, выплачено Σ, к выплате Σ; кнопка «Выплачено» по гиду за месяц (проставляет галочку во всех бронях месяца).
5. **Кнопка «Регламент»** в шапке → модалка с текстом регламента (из `docs/reglament.md`, вшит в HTML при деплое или просто продублирован).

## Регламент (текст, docs/reglament.md)
1. Бронь без гида — не бронь. Гид назначается в день поступления.
2. За 24 ч до выезда гиду уходит карточка выезда (кнопка «Карточка гиду»). Гид отвечает «ок» → галочка «Гид подтвердил».
3. Гид не ответил 2 ч → эскалация Владимиру. Двойное бронирование / замена гида → Владимир.
4. Гид пишет Полине, не Владимиру. Один канал — карточка, без параллельной личной переписки.
5. В день тура после окончания: статус «Проведена», расходы, гонорар гида, отзыв через кнопку.
6. Выручку и цены не менять. Выплаты гидам — Владимир, по сводке «Гиды» раз в неделю/месяц.

## Boundaries
- Always: бэкап index.html перед правкой; деплой только после проверки Playwright; поля Airtable добавлять, не переименовывать.
- Ask first: добавление полей в Airtable (этот спек = запрос), нормализация значений «Гид» в старых бронях.
- Never: удалять поля/записи Airtable; трогать «Сумма»/«Расходы€» существующих броней; менять бот.

## Success Criteria
- В брони гид выбирается только из списка; свободного ввода нет.
- Карточка «Гид не назначен» появляется в «Требуют внимания» для подтверждённой брони без гида.
- Панель «Гиды» показывает по каждому гиду за месяц: туров / гонорар / выплачено / к выплате.
- Кнопка «Регламент» открывает текст из 6 пунктов.
- Все старые брони отображаются как раньше (нет регрессий в календаре/списках).

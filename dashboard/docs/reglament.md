# Регламент: брони и гиды (Sakhva Travel)

Источник истины — Airtable, рабочее место — dash.sakhva-travel.com. Один канал, без дублей.

1. **Бронь без гида — не бронь.** Гид назначается в день поступления брони, из списка «Гиды». Незакрытые висят в «Требуют внимания».
2. **За 24 ч до выезда** гиду уходит карточка выезда (кнопка «Карточка гиду» в брони): дата, время, точка, люди, языки, особенности, оплата на месте. Гид отвечает «ок» → галочка «Гид подтвердил выезд».
3. **Эскалация Владимиру:** гид не ответил 2 ч на карточку · двойное бронирование · замена гида.
4. **Обратный канал — менеджер.** Гид пишет менеджеру, не Владимиру. Всё через карточку, без параллельной личной переписки.
5. **В день тура после окончания:** статус «Проведена», расходы, гонорар гида, отзыв клиенту через кнопку. В тот же день.
6. **Выручку и цены не менять.** Выплаты гидам — Владимир по сводке «Гиды» (кнопка «Выплачено» закрывает месяц по гиду).

Автоподсказки в «Требуют внимания»: гид не назначен · гиду не подтверждено (выезд сегодня-завтра) · закрыть тур (прошёл, статус не проставлен) · нет гонорара.

Данные гидов (телефон, языки, регионы, машина, ставка ₾/день) — Airtable → таблица «Гиды».

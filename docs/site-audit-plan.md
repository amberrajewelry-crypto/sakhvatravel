## Что НЕ трогать (проверено данными)

- **Гео-страницы: ключ «туры в грузию» оставить** — их трафик идёт по «туры в грузию из {город}» (Москва 2319 показов/1997 кликов). Убрать «в Грузию» = убить главный ключ.
- **TouristTrip+Product вместе на 66 карточках** — норма (Product = звёзды, TouristTrip = граф для ИИ).
- **FAQPage** — оставить (помогает ИИ-цитированию, даже без rich snippet).
- **Блок Турция/Египет на хабе** — покрытие структуры ТОП-конкурента, не спам.

## Требует верификации перед правкой

- `/about/` 404 — перепроверить curl (агент может ошибаться, как было с canonical гео).
- x-default→EN на 197 стр — перепроверить grep перед массовым скриптом.
- Точный шаблон Product-блока (block4 tury-v-gruziyu) — свериться перед копированием на 8 хабов.

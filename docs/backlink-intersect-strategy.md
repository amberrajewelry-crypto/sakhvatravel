# Link Intersect — глубокая стратегия аутрича для Sakhva Travel

_Создано 2026-07-17. Развёртка совета из треда evgeny_chichkonakov в рабочую методологию под нишу «частные туры/гид по Грузии» (RU + EN)._

## 0. Что улучшаем в исходном совете

Совет из треда верный, но общий и полу-серый (в списке — Sape, арендные ссылки = токсик). Улучшения под нашу нишу:
1. **Intersect не по всем конкурентам подряд, а по 2 разным пулам** (гиганты-агрегаторы + равные гиды) — доноры у них разного класса, нужны оба.
2. **Фильтр донора не по DR, а по 4 осям** (трафик + тематичность + тип ссылки + гео-язык).
3. **Не «поставьте ссылочку», а обмен ценностью** — под турбизнес есть 5 рабочих оферов, которые повышают отклик кратно.
4. **Карта нишевых доноров Грузии** — то, чего в треде нет вообще (Tourister, Форум Винского, релокант-медиа и т.д.).
5. **Белый уклон** — Яндекс-ниша, арендные/биржевые ссылки = риск Минусинска. Ставка на редакционные + крауд + партнёрские.

## 1. Логика метода (почему intersect работает)

Донор, который уже сослался на 3–4 игроков из топа по «экскурсии Тбилиси / туры в Грузию», — это площадка, которая:
- **тематически открыта** к нашей нише (уже ссылается на туры Грузии);
- **имеет процесс размещения** (принимает гостевые/обзорные/каталожные ссылки);
- **с высокой вероятностью поставит и нам** — мы для неё такой же валидный объект, как конкуренты.

Пересечение = отсев случайных доноров. Домен, ссылающийся на 1 конкурента, — шум; на 3+ — «горячий» донор.

## 2. Пул конкурентов (кого выкачивать)

### Пул A — агрегаторы-гиганты (источник сильных доноров: СМИ, каталоги, тревел-медиа)
| Домен | Что это |
|---|---|
| tripster.ru | Маркетплейс экскурсий №1 RU |
| sputnik8.com | Маркетплейс экскурсий |
| guidego.ru | Маркетплейс гидов |
| weatlas.com | Экскурсии/гиды |
| experience.tripadvisor + tripadvisor.ru | Отзывы/экскурсии |

У них тысячи доноров. Их общие доноры = СМИ и крупные тревел-каталоги. Реалистично взять оттуда каталоги и крауд, не редакции.

### Пул B — равные (малые/средние тур-сайты и гиды по Грузии) — ГЛАВНЫЙ пул
Именно их доноры достижимы для аутрича (тот же вес, что у нас). Определить точный список — задача сбора (см. §7), кандидаты по нише:
- частные гиды Тбилиси с сайтами (georgia4travel, gruzia-gid-подобные);
- локальные турфирмы Грузии с RU-сайтом;
- тревел-блоги, специализирующиеся на Грузии.

**Правило:** intersect считаем ОТДЕЛЬНО по пулу B (приоритет) и по пулу A (добор). Итоговый список = домены, встречающиеся у ≥2 конкурентов пула B ИЛИ ≥3 конкурентов пула A.

## 3. Процесс (5 шагов)

1. **Собрать реферинг-домены** каждого конкурента (§7 — инструменты).
2. **Свести в одну таблицу**, колонка = домен-донор, строки = у каких конкурентов встречается, счётчик пересечений.
3. **Отсортировать по счётчику пересечений** (desc), отсечь single-hit.
4. **Фильтр качества** (§4) — убрать мусор, биржи, дорвеи, нерелевант.
5. **Приоритизация + сегментация под офер** (§5–6) → аутрич.

Таблица-шаблон:
```
donor_domain | intersect_count | конкуренты | DR | traffic/mo | тип(медиа/каталог/блог/форум) | гео/язык | тип_ссылки(редакц/крауд/профиль) | контакт | офер | статус
```

## 4. Фильтр качества донора — 4 оси (не только DR)

| Ось | Брать | Отсекать |
|---|---|---|
| **Трафик** | есть органический трафик (живой сайт) | 0 трафика при высоком DR = PBN/накрутка |
| **Тематичность** | travel / Грузия / релокация / lifestyle | ссылочные помойки, гемблинг, «SEO-доноры» |
| **Тип ссылки** | редакционная в статье, крауд в тему, профиль-каталог | сквозная в подвале, sape-аренда, каталог-свалка |
| **Гео/язык** | RU-контент (осн.), EN для /en/ | нерелевантный язык/регион |

Дополнительно: спам-скор донора, соотношение исходящих ссылок (сайт-«решето» с 500 outbound — мимо), не в кластере уже купленных нами (диверсификация).

## 5. Карта нишевых доноров Грузия-туризм (RU) — то, чего нет в треде

Это «ищи лучше»: конкретные категории + якорные площадки, где ссылка тематична и белая.

| Категория | Площадки-якори | Как получить ссылку |
|---|---|---|
| **Тревел-сообщества/отзывы** | **Tourister.ru**, **Форум Винского (awd.ru)**, otzyv.ru, turizm.ru | отзыв/рассказ/ответ в теме с органичной ссылкой |
| **Тревел-медиа RU** | tonkosti.ru, travel.ru, samokatus.ru, perito-burrito, Тревелвики (aviasales) | гостевая статья/экспертный комментарий/упоминание гида |
| **Релокант-медиа Тбилиси** | сайты и гайды релокантов в Грузию, emigrant-справочники | «услуги гида/трансфера» в разделе досуга |
| **Блоги о Грузии** | персональные тревел-блоги (WordPress) | обзор тура, гостевой пост, взаимо-упоминание |
| **Каталоги/справочники** | 2gis-подобные, гео-каталоги Тбилиси, «гиды Грузии» | регистрация профиля с ссылкой |
| **Гостиницы/гестхаусы** | партнёрские отели Тбилиси | страница «экскурсии от партнёров» |
| **Маркетплейсы-профили** | Tripster/GuideGo/Weatlas профиль гида | заполненный профиль (nofollow, но трафик+бренд) |
| **Wiki** | Wikivoyage/Wikipedia (осторожно) | внешняя ссылка в статье о Тбилиси/Казбеги (высокий барьер) |
| **Свои публикации (parasite)** | Дзен, VC, Habr, Telegra.ph, Medium | статья со ссылкой (уже трекается в parasite_seo) |

**Приоритет по ROI:** Tourister.ru + Форум Винского + релокант-медиа = самый тематичный и живой трафик, низкий риск. С них и начинать.

## 6. Аутрич — сегментация и оферы

Не «поставьте ссылку». Под каждый сегмент — свой офер (кратно поднимает отклик):

| Сегмент донора | Офер (что даём взамен) |
|---|---|
| Тревел-блог | готовая экспертная гостевая статья (мы пишем) + фото маршрутов |
| Медиа/редакция | экспертный комментарий гида (лицензия, 5 лет опыта) — журналистам нужен эксперт |
| Релокант-сообщество | реальная польза: гайд «первые дни в Тбилиси», спец-условие для участников |
| Отель/гестхаус | реферальная комиссия / кобрендинг экскурсий для их гостей |
| Форум/Q&A | развёрнутый полезный ответ, ссылка — как источник, не реклама |
| Каталог | просто заполнить профиль |

**Каналы контакта (как в треде):** e-mail вебмастеру + личка (Telegram/форма). Для медиа — редакция/автор статьи напрямую.

**Шаблон письма (блог, RU):**
> Тема: Гостевой материал о Грузии для [блог]
> Здравствуйте, [Имя]. Читаю [блог], особенно понравился материал про [конкретная статья]. Я — Тимур, лицензированный гид по Грузии (5 лет, [лицензия]). Готов написать для вас эксклюзивный материал — например «[тема под их аудиторию]» с авторскими фото маршрутов, бесплатно. Взамен — ссылка на мой сайт в теле. Прислать черновик?

Персонализация первой строки (упоминание конкретной статьи донора) — обязательна, иначе спам-отклик.

## 7. Инструменты сбора БЕЗ Ahrefs (free-стек)

Ahrefs API по текущему плану недоступен. Реальные пути собрать доноров:

| Инструмент | Что даёт | Стоимость |
|---|---|---|
| **Ahrefs Free Backlink Checker** | топ-100 бэклинков/домен, DR | free (веб, лимит) |
| **Bing Webmaster Tools** (у Sakhva верифицирован) | наши входящие + отчасти конкурентов | free |
| **GSC Links** (верифицирован) | наши входящие ссылки/анкоры | free |
| **Yandex Webmaster** (верифицирован) | наши входящие, анкоры | free |
| **Moz Link Explorer free** | 10 запросов/мес, топ-доноры | free tier |
| **Ubersuggest / SEO SpyGlass free** | бэклинки с лимитом | free tier |
| **Common Crawl web graph** | доноры из открытого веб-графа | free (тех. сложно) |
| **DataForSEO API** (MCP есть) | полный intersect по API | ~$0.02–0.10/запрос, платно |

**Ручной intersect на free-стеке:** прогнать 4–5 конкурентов через Ahrefs Free Checker (топ-100 каждого) → свести домены → пересечения топ-100 уже дают ядро сильнейших доноров (самые мощные ссылки конкурента в топ-100 попадают). Неполно, но 80% ценности за 0₽.

**Полный автоматический intersect:** только DataForSEO (платно) — если решим, оценю точную стоимость ДО запуска.

## 8. KPI, темп, анкор-план

- **Темп:** 5–15 качественных ссылок/мес (белый, безопасный для Яндекса). Резкий всплеск = риск Минусинска.
- **Анкоры (безопасное распределение):** 50–60% брендовые/URL («Sakhva Travel», «sakhva-travel.com»), 25–30% безанкорные/общие («тут», «по ссылке», «сайт гида»), 10–15% разбавленные ключи («частный гид в Тбилиси»), <5% точных коммерческих ключей. Переспам точным анкором «экскурсии в тбилиси» = прямой сигнал накрутки.
- **KPI 90 дней:** 15–30 тематичных доноров, рост ref.domains, отслеживать в GSC/Yandex Webmaster.

## 9. Риски

- **Sape/арендные (из треда) — НЕ брать.** Токсик, снимаются, фильтруются.
- **Биржи (Miralinks/GoGetLinks) — серо.** Работают, но против правил; если брать — только тематичные редакционные, малой долей.
- **Анкор-переспам** — см. §8.
- **Массовая закупка** — плоский взрывной прирост палится. Только органичный темп.

## 10. Привязка к текущей стратегии Sakhva

Ссылочное у нас исторически НЕ приоритет (рост ведём через on-page/техСЕО до эталона; ПФ отдельно). Данная стратегия — **дополнительный канал**, включать по решению. Наибольший смысл — для **/en/ версии** (EN-выдача Google ранжируется больше по ссылкам, чем RU-Яндекс) и для укрепления E-E-A-T гида (ссылки из тревел-медиа = сигнал экспертности).

**Первый практический шаг (0₽):** Tourister.ru + Форум Винского — 3–5 полезных рассказов/ответов с органичной ссылкой на конкретные туры. Тематично, живой трафик, белее некуда.

# ТЗ: Усиление хаба /ekskursiya/ (контент-гэп vs топ-3)

**Дата:** 2026-06-25
**Объект:** `ekskursiya/index.html` (RU) + `en/ekskursiya/index.html` (EN-паритет обязателен)
**Цель:** закрыть контентный разрыв с топ-3 (Sputnik8/Tripster/GuideGo) — добавить информационные блоки вокруг «экскурсии в Грузии», которыми топ держит интент. НЕ копировать маркетплейс-механику.
**База данных:** `data/catalog.json` (67 записей, 18 тегов), `catalog-en.json`. Бренд-рейтинг 4.9/90 (реальный, с index.html). Отзывы — переиспользовать с главной (10 Review-маркеров). FAQ-паттерн — копировать с `ekskursiya/art-tur-tbilisi/`.

## Ограничения (жёсткие)
- НЕ трогать `main.js`.
- `node scripts/predeploy-check.js ekskursiya/index.html en/ekskursiya/index.html` перед деплоем, 0 ошибок.
- EN-версия = RU по блокам (не ломать RU при правках EN).
- Фейков нет: per-tour рейтинг не выдумывать (см. P2/блокер данных).
- Прогресс необратим, без отката.

## P0 — строится на текущих данных, максимальный SEO-эффект

### 1. Тематические категории-подборки
- **Что:** секция «Экскурсии по темам» — карточки-якоря по 18 тегам каталога (За городом 21, Старый Тбилиси 8, Многодневные 8, Активный 7, Казбеги/Кахетия/Винные/Горные ×6, Гастро/Мастер-классы ×4, Для детей 5, Сезонные/Романтика/Пешеходные/Фото/Батуми/Ночные/Релоканты).
- **Где:** новая секция между каталогом и футером.
- **Данные:** теги уже в catalog.json — фильтрация JS по data-tag (паттерн фильтра хаба уже есть).
- **SEO:** каждая тема = longtail («гастрономические экскурсии грузия», «горные туры грузия»). H2 «Экскурсии по темам» + H3 на тему.
- **Готово когда:** 8-12 топ-категорий выведены секцией, клик скроллит/фильтрует каталог по тегу.

### 2. FAQ на хабе + схема
- **Что:** блок «Частые вопросы» (6-8 Q&A: как забронировать, языки, группа/индивидуально, цены, отмена, дети, сезон).
- **Данные:** копировать JSON-LD `FAQPage` паттерн с `ekskursiya/art-tur-tbilisi/`.
- **Готово когда:** видимый блок + валидный FAQPage в schema (predeploy ✅).

### 3. Лента отзывов на хабе
- **Что:** секция «Что говорят путешественники» — 4-6 реальных отзывов.
- **Данные:** переиспользовать Review-данные с index.html (реальные, уже на сайте).
- **SEO:** E-E-A-T + Review-схема.
- **Готово когда:** лента отрисована, отзывы реальные, без дублей схемы Review с туром.

### 4. Агрегат-счётчик в шапке хаба
- **Что:** строка «67 авторских экскурсий · рейтинг 4.9 из 90 отзывов» под H1.
- **Данные:** count из catalog.json (динамически), 4.9/90 с бренд-схемы.
- **Готово когда:** счётчик считает реальное число записей.

### 5. Блок «Экскурсии в других городах»
- **Что:** перелинковка кластеров — Батуми (3), Кутаиси, Казбеги, Кахетия.
- **Данные:** города из catalog.json.
- **SEO:** перелинковка + интент «экскурсии в <город>».
- **Готово когда:** ссылки на гео-кластеры с тематическими анкорами.

## P1 — контент (написать копирайт)

### 6. «Чем различаются форматы экскурсий»
- Объяснитель: групповая / индивидуальная / мастер-класс / многодневный тур — для кого, цена, плюсы. H2 + таблица или 4 карточки.
- Данные format/type/price из каталога для якорения.

### 7. «Что посмотреть в Грузии» (мини-гид)
- 6-8 топ-направлений (Казбеги, Кахетия, Боржоми, Сванетия, Вардзия, Уплисцихе…) → ссылки на соответствующие экскурсии/блог.
- SEO: перехват инфо-интента «что посмотреть» с воронкой в туры.

### 8. Бейджи на карточках
- Из существующих данных: «Многодневный» (days>0), «Группа»/«Индивидуально» (format), «Мастер-класс» (tag), «Без предоплаты» (если политика реально такая — уточнить у владельца).
- НЕ добавлять «Хит продаж» без реальных данных продаж.

## P2 — требует РЕАЛЬНЫХ данных (блокер, не выдумывать)

### 9. Per-tour рейтинг/число отзывов на карточке
- **Блокер:** в catalog.json нет рейтинга по каждому туру. Топ-3 показывают звёзды+N отзывов на карточке.
- **Источник:** реальные отзывы из Airtable CRM / Google Reviews по каждому туру.
- **Действие:** собрать реальные данные → добавить поля `rating`,`reviewsCount` в catalog.json → рендерить. БЕЗ реальных данных — не делать.

## Чего НЕ делаем (маркетплейс-инфраструктура single-guide не тянет)
- Бронь+оплата с выбором даты в каждой карточке, мгновенное подтверждение, 24/7 колл-центр, гонка за объёмом «N сотен экскурсий».

## Порядок
P0 (1→5) одним заходом → predeploy → деплой RU+EN → P1 (6→8) → P2 после сбора реальных отзывов.

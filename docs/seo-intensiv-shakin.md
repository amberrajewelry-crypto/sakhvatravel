## 1. Индексация — фундамент видимости

«Нулевой» этап аудита. Без 100% уверенности, что целевые страницы доступны и легитимны для роботов, работа над контентом/ссылками бессмысленна.

**Протокол анализа (Checklist):**
- **Суть:** сквозное сопоставление списка URL из `Sitemap.xml` и краулинга (Screaming Frog) с данными GSC API и Yandex Webmaster.
- **Инструменты:** GSC API + Looker Studio (обязательно для проектов >1000 стр — обход лимитов интерфейса), Yandex Webmaster, Screaming Frog SEO Spider.
- **KPI (пороги доли проиндексированных):**
  - **>80%** — здоровое состояние.
  - **60–80%** — зона риска, точечный анализ выпавших.
  - **<60%** — критично, срочный **Content Relevance Audit**.
- **Expert Note:** падение <60% часто от «мусорного» контента. Пример: на Fintech-проекте внезапно появляются новости о ценах на помидоры → поисковик считает раздел нерелевантным спамом → пессимизация всего раздела. Удаление «зомби-страниц» = единственный путь восстановить краулинговый бюджет.

## 2. CTR и поведенческие факторы — оценка эффективности

CTR = маркер соответствия страницы интенту. Низкий CTR при наличии показов = проблема сниппета/релевантности (страница уже имеет «кредит доверия» от алгоритма, но не конвертит в трафик).

**Матрица классификации (Protocol):**
- **Формула сегментации:** CTR страницы < 50% от среднего по сайту → статус «Требует доработки».
- **Инструменты:** GSC, Yandex Webmaster, авто-обработка в Google Sheets/Excel.

| Статус | Позиция / состояние | Действие |
|---|---|---|
| **CTR OK** | в рамках нормы | оставить «как есть», плановый мониторинг |
| **Snippet Issue** | Топ-10, низкий CTR | UX/UI сниппета: рерайт Title/Description, микроразметка |
| **Intent Mismatch** | Топ-30, нет кликов | глубокий рерайт под интент, анализ конкурентов в выдаче |
| **Zombie Page** | нет показов и кликов | удаление, склейка (301) или Canonical |

→ Масштабирование на тысячи URL требует автоматизированного SEO-стека.

## 3. Нейросети и вайб-кодинг — новый стандарт разработки

Senior SEO-стратег = архитектор систем. Владение промптом заменяет знание синтаксиса → **Rapid MVP Deployment** (сборка кастомных инструментов за часы) → **Automated SEO Stack**, работающий автономно.

**Методы AI-оптимизации:**
- **Knowledge Graphs (графы знаний):** таксономии и связи через **Триплеты (Субъект-Предикат-Объект)** — AI понимает архитектуру сайта на уровне сущностей, а не ключевых слов.
- **Стек архитектора:**
  - **Cursor (IDE)** — основная среда вайб-кодинга и быстрой правки кода.
  - **Claude (Sonnet)** — лучшая модель для генерации чистого кода и экспертных текстов.
  - **Perplexity** — анализ живой выдачи, сбор LSI-данных.
  - **Gemini** — массовая сегментация данных, работа с контекстом.
- **Стратегическая связка:** сущности из графа знаний → напрямую в GEO-продвижение (LSI в отзывах). «Кросс-поллинация» данных = семантическая монолитность проекта.

## 4. Python-инструменты SEO — кастомная автоматизация

Профессиональное SEO невозможно без своего стека на Python — единственный способ обойти лимиты публичных сервисов и реализовать авторские скоринговые модели.

- **Библиотеки:** Pandas (данные), **Mystem** (лемматизация от Яндекса), API-интеграции (XMLRiver, Wordstat).
- **Функционал «ТекстМир»:** выявление переспама (over-optimization) и извлечение скрытых LSI-фрагментов из пассажей конкурентов. Анализ не плотности слов, а **семантического окружения ключа в Топе**.
- **Weighted Average Scoring (средневзвешенный скоринг доноров):** оценка не по одной метрике (DR), а по формуле трафик + DR + индексация одновременно → отсекает площадки с накрученными пузомерками. Автоматизация анализа доноров = безопасность линкбилдинга.

## 5. Ссылки — стратегия безопасного веса

В условиях антиспам-фильтров — **Safety Protocol**: многоуровневое (Tiered) построение ссылочной массы = «изоляция рисков». Основной домен получает только чистый вес от Tier 1; агрессивное продвижение — на нижних уровнях.

- **Tier 1:** максимальное качество (Miralinks, жирные PBN). Доля проиндексированных статей у донора должна быть **>70%**.
- **Tier 2/3:** усиление Tier 1 через GSA и Xrumer.
- **Золотая пропорция:** 1:10 (на 1 ссылку Tier 1 — 10 ссылок Tier 2).
- **Risk Insulation:** если Tier 2 попадает под фильтр — отсекаем ветку, сохраняя безопасность Tier 1 и основного домена.

→ Для локального бизнеса ссылочный вес синхронизируется с активностью в геосервисах.

## 6. GEO и геосервисы — доминирование в локальном поиске

В 2025–2026 карточка в Яндекс.Картах / Google Maps эффективнее лендинга. Битва за **«Last Click»** — момент финального решения о покупке. Цель — полная UX/UI оптимизация карточки бизнеса.

**Методы доминирования:**
- **EXIF Data Stitching:** инструмент **Geosetter** — прошивка фото координатами и ключевыми словами в метаданных ПЕРЕД загрузкой.
- **QR-code Feedback Loop:** микро-сайт/чат-бот как фильтр отзывов — положительные направляются на карты, отрицательные во внутреннюю поддержку. Удержание рейтинга **4.7–5.0**.
- **LSI-оптимизация ответов:** сущности из AI-триплетов (Блок 3) при ответах на отзывы → расширяет семантическое облако карточки без риска переспама.
- **Активность:** регулярное обновление прайс-листов (до 500 позиций) и сторис.

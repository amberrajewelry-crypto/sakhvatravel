# План: убрать внутреннюю каннибализацию «туры в грузию» → один хаб (Яндекс)

_Переписано 2026-07-04. Источник ранкинга — Яндекс.Вебмастер query-analytics (реальные показы/клики). Search API region 225 НЕ используется как источник ранкинга (даёт обезличенную OTA-выдачу, а не наш реальный ранк)._

## Цель

1. **0 внутренних каннибалов** на голый «туры в грузию» — только хаб `/tury-v-gruziyu/` таргетит фразу.
2. **Рост частоты показов хаба** по «туры в грузию». Яндекс уже ранжирует нас высоко (см. диагноз), но показывает редко из-за распыления релевантности по 6 страницам.
3. Ноль редиректов. Все URL сохранены. Правки только HTML + интент.

## Диагноз (по Вебмастеру, не по Search API)

- **Мы УЖЕ в топе, когда Яндекс нас показывает:**
  - «туры в грузию 2026» — поз **1.3-1.5**, 237 показов.
  - голый «туры в грузию» — доходил до поз **1.0** (2 июля), но показов мало (1-3).
- **Проблема не «пробить топ», а частота показов.** Яндекс распыляет сигнал: голый ВЧ тянут на себя 6 наших URL одновременно.
- **Внутренние каннибалы голого ВЧ (Вебмастер):** главная (поз 3.5, 6619 показов), хаб `/tury-v-gruziyu/`, `/ekskursiya/tur-gruziya-leto/`, `avtorskie`, `ekskursionnye`, `individualnyy`.
- **Ссылочный сигнал уже сфокусирован на хаб** (636 анкоров «туры в грузию», 281 входящая) — это плюс, добивать перелинковку не нужно.
- **Спрос по формулировкам (Вебмастер, важно для разводки):**
  - «экскурсионные туры в грузию» — **4832 показа** → «в Грузию» НЕЛЬЗЯ выпиливать со страницы ekskursionnye.
  - Формулировки без «в грузию» («частный гид» = 1, «личным гидом» = 0) — мёртвые.

## Этапы

### Этап 0 — Разводка каннибалов on-page (ГЛАВНОЕ)

Каждый из 6 URL уводим от голого «туры в грузию» в свой уникальный интент, кроме хаба:

| URL | Куда уводим | Ключ, который остаётся |
|---|---|---|
| `/` главная | «Экскурсии по Грузии с гидом» | экскурсии по грузии |
| `/tury-v-gruziyu/` ХАБ | зонтичный «Туры в Грузию 2026 — виды, цены, маршруты» | **туры в грузию** (единственный) |
| `ekskursionnye-tury-v-gruziyu` | «Экскурсионные **туры** в Грузию без перелёта» (акцент без перелёта) | экскурсионные туры в грузию (4832) |
| `individualnyy-tur-v-gruziyu` | «Индивидуальный тур по Грузии — своя группа» | индивидуальный тур |
| `avtorskie-tury-v-gruziyu` | «Авторские туры по Грузии» | авторские туры |
| `ekskursiya/tur-gruziya-leto` | «Летний тур по Грузии» (сезонный интент) | тур в грузию летом |

**КОРРЕКЦИЯ прошлой правки:** ekskursionnye/individualnyy ранее выпилили «в Грузию» полностью (12→0, 7→0). Откатить — оставить «туры в Грузию» (ключ имеет спрос 4832), развести через акцент/контекст «без перелёта / своя группа», а не удалением ключа.

**Главная — добить консолидацию на хаб:**
- title/H1/og/desc → «Экскурсии по Грузии» (сделано, не задеплоено).
- JSON-LD `name` «Экскурсии **и туры** по Грузии» → убрать «и туры».
- Ссылку главная→хаб с анкором «Туры в Грузию» усилить (в теле/футере, не только в меню) — передаёт авторитет главной хабу.

### Этап 1 — Контент хаба под интент (главный рычаг частоты)

- Блоки, которые ждёт голый ВЧ: форматы (с проживанием/трансфером/N дней), «цены от X ₽», сравнение пакет vs экскурсионный, FAQ «нужен ли перелёт».
- Структура: виды → цены → как выбрать → отзывы → CTA. +1000 слов.
- Блок Турция/Египет НЕ трогать — это осознанное покрытие структуры ТОП-конкурента (у OTA такие направления в выдаче есть), не спам.

### Этап 2 — Product-звёзды (рычаг CTR → ПФ → частота)

- 12× TouristTrip на хабе → Product+Offer (TouristTrip звёзд не даёт).
- На споках (ekskursionnye/individualnyy/mnogodnevnye) добавить Product+aggregateRating.
- Убрать дубль Product на avtorskie.
- Звёзды в сниппете → выше CTR → лучше ПФ → Яндекс поднимает и **чаще показывает** хаб.

### Этап 3 — Авторитет (внешний фронт, отдельно)

- Внешние ссылки на хаб против OTA (DR 80+). Долго/дорого, не блокирует Этапы 0-2.

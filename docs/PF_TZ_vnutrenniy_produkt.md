# ТЗ по ПФ — внутренний продукт (экскурсии + туры по длительности)

_Составлено: 2026-07-24. Источники: Яндекс.Вебмастер (спрос+позиции, 30д), Метрика 109038950 (живой трафик+конверсии, робот-фильтр 6.6%)._

## Главный вывод (честно)

Твой внутренний продукт — экскурсии из Тбилиси, туры по Грузии, туры по длительности (3/5/7/10 дней), Казбеги, Кахетия — **уже стоит в топ-1 по всему ядру спроса** (позиции 1.1–1.6, показы 7–13 тыс). Там ПФ **потолок выбран**: лить новый ПФ на эти запросы = деньги в трубу, выше первого места не подняться.

Гео-туры из городов РФ (Москва/СПб/Казань…) — **исключены**: не твоя целевая, ты локальный гид, не авиапакеты.

Значит стратегия делится на **три задачи, а не «лить ещё»**:
- **A. Рост** — 1 крупная цель + фразовые варианты (там позиция НЕ топ-1).
- **B. Оборона** — удержание топ-1 по конвертящим (ПФ-позиции проседают без потока кликов).
- **C. Не трогать** — где потолок или не целевая.

## БЛОК A — РОСТ (новый ПФ сюда, ~55% бюджета)

Единственные точки внутри продукта, где позиция > 2 и есть куда двигать.

| # | Целевая страница | Главный анкор-запрос | Показы/30д | Поз. сейчас | Цель | Приоритет |
|---|------------------|----------------------|-----------:|:-----------:|:----:|:---------:|
| A1 | `/ekskursiya/ekskursiya-borjomi-iz-tbilisi/` | экскурсия боржоми из тбилиси | 3802 | **4.0** | 1–2 | **★★★** |
| A2 | `/ekskursiya/tur-gruziya-3-dnya/` | тур в грузию на 3 дня | 159 | 3.7 | 1 | ★★ |
| A3 | `/ekskursiya/tur-gruziya-10-dney/` | тур в грузию на 10 дней | 172 | 3.5 | 1 | ★★ |

**A1 Боржоми — цель №1.** 3802 показа, позиция 4.0, страница есть. Единственный крупный запрос ядра НЕ в топе. Поднять с 4 → топ-2 = основной прирост живого трафика этого ТЗ.
Доп-анкоры на ту же страницу: `боржоми экскурсия`, `экскурсия в боржоми из тбилиси`, `боржоми из тбилиси`, `парк боржоми экскурсия`.

**A2/A3 — фразовые варианты «на N дней».** Тонкость: «тур грузия 3 дня» уже поз 1.2, а «тур в грузию **на** 3 дня» — поз 3.7 (та же страница, другая формулировка запроса). ПФ по варианту с предлогом добивает подстроку до топа. Анкоры: `тур в грузию на 3 дня`, `тур по грузии на 3 дня`, `3 дневный тур грузия` (A2); `тур в грузию на 10 дней`, `тур по грузии на 10 дней 2026` (A3).

ПФ-позиции затухают без потока кликов. Держим **ровный поддерживающий поток** (не наращивание) по конвертящим топ-1. Это защита выручки, не рост позиции.

## БЛОК C — НЕ ТРОГАТЬ

- **Гео-города РФ** (из Москвы/СПб/Казань/Ереван/…) — не целевая. ПФ = 0.
- **Авторские туры** (поз 1.5–1.8, 8893 показа) — почти топ, низкий приоритет; если останется бюджет — 5% на `авторские туры в грузию` (поз 1.8→1).
- **Инфо-запросы** без конверсии (`ботанический сад тбилиси` 3.8, `тбилиси за 3 дня` блог) — трафик без брони, ПФ не лить.

## Распределение ПФ-бюджета

```
A. РОСТ           55%  ── Боржоми 40% + варианты «на N дней» 15%
B. ОБОРОНА        40%  ── ровный поддерживающий поток по топ-1 конвертящим
C. Авторские      5%   ── опционально, если есть остаток
```

## Метрики контроля (снимать раз в 2 недели)

- Боржоми: позиция 4.0 → ≤2.0 (главный KPI роста).
- «тур в грузию на 3/10 дней»: 3.5–3.7 → ≤1.5.
- Оборона: ни один якорь Блока B не должен уйти ниже позиции 2.
- Живой трафик (Метрика, робот-фильтр) на страницы A1–A3 — должен расти вместе с позицией; если позиция растёт, а живые визиты нет — ПФ греет позицию впустую (как было с Сигнахи: поз 1.3 при 1 живом визите).

## Проверенные факты, на которых стоит ТЗ

- Робот-фильтр Метрики: 6.6% (не «99% боты» — та оценка снята).
- Яндекс — основной канал: 3612 визитов / 36 конверсий за 30д (×2.4 трафика и ×2.8 конверсий к Google).
- Все страницы Блока A и B **существуют** на проде (проверено).
- Каннибализации внутри длительности нет: `3-dnya / 5-dney / 7-dney / 10-dney` — отдельные URL.

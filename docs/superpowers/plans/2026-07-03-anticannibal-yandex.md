# Устранение всех каннибалов Sakhva — по данным ЯНДЕКСА

**Goal:** Ни одного каннибала. За каждый коммерческий интент — ровно один URL. Каннибалов
не разводим косметикой (title), а либо перестраиваем полностью (меняем целевой интент), либо удаляем.

**Источник ранжирования:** Yandex.Webmaster query-analytics (host https:sakhva-travel.com:443),
не Google. Сайт живёт на Яндексе.

**Принципы:**
- Редиректы НЕ создаём. Удаление = страница уходит (0 показов, терять нечего). Перестройка = URL
  сохраняется, меняется контент/интент/schema.
- RU↔EN парность: перестраиваемые 3 страницы EN-пар не имеют — EN не трогаем.
- Выполнение лично через Edit/Read/Bash. Деплой — только по команде Владимира.

## БЛОК 1 — Перестройка 3 каннибалов (вариант А: «изменить всё»)

Меняется весь целевой интент: title, H1, meta description, og/twitter, lead, тело (убрать
коммерческие маркеры «цена/заказать/из Тбилиси»), schema-тип, внутренние анкоры. URL сохраняется
(уже в sitemap). Цель — увести страницу с запроса, который держит коммерческий лендинг.

### 1.1 `blog/kazbegi-iz-tbilisi-2026` → инфо-путеводитель «Казбеги: что посмотреть»
- **Каннибал:** #1.6 за «казбеги из тбилиси» (2004 кл) — коммерческий интент, дублирует лендинг
  `ekskursiya/ekskursiya-kazbegi-iz-tbilisi` («экскурсия казбеги» 1030 + «экскурсия казбеги из тбилиси» 1053).
- **Стало:** чистый информационный гид. Целевой запрос «казбеги что посмотреть / достопримечательности /
  Гергети / Гвелети» (сейчас пустует).
- **Правки:** title/H1/description/og/twitter; lead; тело — убрать «заказать/цена/из Тбилиси», добавить
  «маршрут, Троицкая церковь Гергети, водопад Гвелети, как добраться, треккинг»; schema `BlogPosting`
  (не Product); внутр-блок «Забронировать экскурсию в Казбеги →» на лендинг, анкор ≠ заголовку.
- **Verify:** Яндекс — за «казбеги из тбилиси» остаётся только лендинг.

### 1.2 `blog/sernye-bani-tbilisi` → инфо «Абанотубани: история и архитектура бань»
- **Каннибал:** #2–6 за «серные бани тбилиси» (38 кл) — пересекается с лендингом
  `ekskursiya/ekskursiya-abanotubani` (#1.9–2.5 за «...с гидом / забронировать / цена»).
- **Стало:** история района Абанотубани, легенда основания Тбилиси, архитектура, виды бань. Запрос
  «абанотубани / история серных бань».
- **Правки:** title/H1/description/og; lead; тело — убрать «цена/сколько стоит/забронировать»;
  `BlogPosting`; ссылка «Экскурсия в серные бани с гидом →» на лендинг.

### 1.3 `tury-v-batumi` (ХАБ) → «Батуми: отдых, пляжи, что посмотреть» (направление)
- **Каннибал:** хаб конкурирует за «туры в батуми из тбилиси» с лендингом
  `ekskursiya/tur-batumi-iz-tbilisi` (1929+829 кл). Реальных небрендовых запросов у хаба нет — только
  брендовые «...sakhva-travel com».
- **Стало:** страница-направление о городе/курорте: пляжи, набережная, что посмотреть, когда ехать,
  как добраться. НЕ «туры из Тбилиси». Запрос «батуми отдых / что посмотреть в батуми / пляжи батуми».
- **Правки:** title/H1/description/og; lead; секции — убрать оффер-блок «туры из Тбилиси от ₾…»,
  заменить контентом о городе; schema `TouristDestination`/`Place` (не Product); внутр-ссылка
  «Тур в Батуми из Тбилиси с гидом →» на лендинг.

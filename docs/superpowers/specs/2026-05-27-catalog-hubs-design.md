# Spec: Каталог экскурсий и туров — Tripster-модель

**Дата:** 2026-05-27
**Статус:** Утверждён (v2 — после инженерного ревью)
**Фаза:** 1 (структура и навигация)

## Цель

Реорганизовать каталог экскурсий и туров на sakhva-travel.com по модели Tripster: hub-страницы с фильтрами, pill-тегами рубрик и сеткой карточек. Все существующие URL сохраняются.

## Терминология

- **Экскурсии** — всё однодневное (~51 страница): Казбеги, Кахетия, Батуми, пешие, гастро, фото, ночные, мастер-классы и т.д.
- **Туры** — только многодневные от 2 дней (8 страниц): 3/5/7/10 дней, Грузия+Армения, Вся Грузия и т.д.

## Scope

### Делаем

1. **Скрипт-парсер** — обход 59 подстраниц, извлечение данных, автоматическая разметка рубрик → JSON
2. **Hub "Экскурсии"** — переделка `/ekskursiya/index.html` в каталог с фильтрами и карточками
3. **Hub "Туры"** — новая страница `/tury/index.html` (новый URL, нужна индексация)
4. **Живой календарь** — datepicker с данными из Airtable `/api/spots`
5. **Breadcrumbs + BreadcrumbList schema** — на hub-страницах и категорийных

### Не трогаем

- Главную страницу (hero, nav, секции карточек, footer)
- 59 подстраниц экскурсий (дизайн, контент, SEO)
- Блог (77 RU + 59 EN статей)
- About, Contacts, Gallery, Partner
- Geo-страницы (/tury-v-gruziyu-iz-*) — контент не меняем, они получают трафик от фильтра "Откуда едете"
- Footer
- API endpoints
- main.src.js (модалы, booking, калькулятор)
- EN версию (пока)

## Шаг 0: Скрипт-парсер данных

Node.js скрипт проходит по всем 59 подстраницам `/ekskursiya/*/index.html`:
- Извлекает: title, meta description, hero image path, цена (GEL/USD), длительность
- Автоматически размечает рубрики по содержимому (ключевые слова в title/description)
- Определяет тип: экскурсия (городская/тематическая) или тур (выездной/многодневный)
- Определяет формат: индивидуальная / мини-группа
- Результат: `data/catalog.json` — единый источник данных для обоих hub-страниц

## Hub "Экскурсии" (`/ekskursiya/index.html`)

### Шапка

```
Breadcrumbs: Главная > Экскурсии
H1: Экскурсии в Тбилиси и Грузии
Подзаголовок: Авторские экскурсии на русском языке. Цены от ₾94
```

### Фильтры (4 dropdown в одну строку)

1. **Даты, 1 чел.** — живой datepicker + Airtable `/api/spots` (реальная занятость) + выбор кол-ва человек
2. **Формат проведения** — Индивидуальная / Мини-группа (1-8 чел.)
3. **Откуда едете** — dropdown: Уже в Тбилиси / Москва / СПб / Минск / Ереван / Казань / Ташкент / Екатеринбург. Клик → **редирект на geo-страницу** (`/tury-v-gruziyu-iz-moskvy/` и т.д.)
4. **Валюта** — GEL / USD / EUR / RUB (пересчитывает цены на карточках на клиенте)

### Pill-теги (без заголовка, тематические + географические)

```
[Все 51] [Пешеходные] [Гастро] [Винные] [Фото] [Ночные] [Старый Тбилиси] [Мастер-классы] [Для детей] [Казбеги] [Кахетия] [Батуми]
```

Теги с автоподсчётом количества. Клик фильтрует карточки на клиенте (без перезагрузки).

### Карточки (сетка 3 колонки desktop, 1 mobile)

Каждая карточка:
- Фото (hero с подстраницы)
- Бейдж формата: "Индивидуальная" (зелёный #1A3D2E) / "Мини-группа" (янтарный #F59E0B)
- Длительность (правый верхний угол)
- Название
- Краткое описание маршрута (2 строки, CSS clamp)
- Цена в выбранной валюте
- Рейтинг: ★ 4.9 (87 отзывов) — единый рейтинг гида с вариациями формулировки

Клик → переход на существующую подстраницу `/ekskursiya/[slug]/`.

## Breadcrumbs

Формат: `Главная > [Раздел]`

Примеры:
- Hub экскурсий: `Главная > Экскурсии`
- Hub туров: `Главная > Туры`
- Категория: `Главная > Винные туры в Грузии`

Schema: BreadcrumbList JSON-LD на каждой странице.

## Данные для карточек

1. **Скрипт-парсер** (`scripts/parse-catalog.js`) обходит 59 подстраниц → генерирует `data/catalog.json`

3. Фильтрация/pill-теги работают на клиенте через JS
4. Пересчёт валюты — на клиенте, курсы из существующего калькулятора в main.src.js

## Топ-7 критических проблем

1. **Мёртвые страницы с активной schema** — `/tour/emigrant/` и `/tour/old-tbilisi/` referenced в schema/sitemap/nav, но файлов нет (0 HTML)

4. **25.7 MB background video** — `tours-bg-video.mp4` без сжатия, скачивается у каждого посетителя

7. **AggregateRating типы данных** — bestRating/worstRating как строки ("5"), должны быть числа (5)

## Дополнительные находки (полный отчёт агентов)

### Новые критические (не были в первом резюме)

**CRITICAL — Мёртвые tour страницы:**
- `/tour/emigrant/` — нет файла, но есть в homepage schema как TouristTrip, в nav, в sitemap
- `/tour/old-tbilisi/` — то же самое
Это dead links с активной schema: Google краулит, получает 404, schema на homepage невалидна.

**CRITICAL — JS redirect перехватывает Googlebot:**
Технический агент обнаружил: Googlebot при первом краулинге имеет пустой localStorage. Скрипт определяет язык бота как не-RU и редиректит на `/en/`. Это означает что Google может индексировать EN-версию как primary для русских туров. Правильное решение — server-side redirect через Vercel middleware с `Accept-Language` header.

**HIGH — x-default указывает на RU, должен на EN:**
`hreflang="x-default"` → `https://sakhva-travel.com/` (RU). Для сайта, целящегося в international travelers, x-default должен указывать на EN версию. Это затрагивает 211 страниц.

**HIGH — Scaled content risk (EN blog):**
42 RU статьи vs 56 EN статей. 46 EN статей были созданы в одну сессию (02-03.05). Google March 2024 algo специально флагирует "scaled content abuse" — bulk-created articles targeting search terms. Необходим контент-аудит новых EN статей.

**HIGH — Несоответствие цен:**
- About page: Казбеги от ₾205, Ночной Тбилиси от ₾165
- Homepage schema: Казбеги ₾175, Ночной Тбилиси ₾94
- llms.txt: другие цифры
Trust signal для QRG рейтеров — конфликтующие цены = недоверие.

**MEDIUM — Опечатки в llms.txt:**
"русскоязычый" (пропущена буква), "ет." вместо "нет.", "сран" вместо "стран". AI системы оценивают лингвистическое качество.

### Критические ошибки

**CRITICAL:** `sameAs` массив на TravelAgency (homepage) содержит обрезанный URL Google Maps — это вызывает silent JSON parse error или дропает запись. Проверить в source и исправить.

**FAIL:** BreadcrumbList на /tours — последний ListItem не имеет `item` URL. Google требует `item` на всех ListItems кроме последнего (но без него rich result не работает).

**FAIL:** `bestRating` и `worstRating` в AggregateRating переданы как строки (`"5"`, `"1"`), должны быть числа (`5`, `1`).

**FAIL:** Индивидуальные Review nodes не имеют `bestRating`/`worstRating` — обязательно для Google Review rich results.

### Упущенные возможности

- **SearchAction** на WebSite — sitelinks searchbox в Google
- **Person schema для Тимура** — отдельный Person тип с `@id` как на About page
- **ProfilePage** для About page
- **GeoCoordinates** на TouristTrip страницах (есть только на homepage TravelAgency)

## 4. Performance / Core Web Vitals (62/100)

### TTFB — ОТЛИЧНО
| Метрика | Значение |
|---------|---------|
| TTFB homepage | ~115ms |
| TTFB tours | ~260ms |
| CDN | Cloudflare (cache HIT) |

### CRITICAL: Background Video
`tours-bg-video.mp4` = **25.7 MB**. Это критически большой ассет:
- Загружается без `lazy`/`IntersectionObserver`
- Нет условной загрузки для мобильных (хотя сам видеоэлемент скрыт на мобилке CSS)
- Рекомендация: конвертировать в WebM + MP4 < 3MB, или заменить на статичный poster на мобилке

### HIGH: LCP редирект для EN
Lang-redirect script находится на позиции ~66 байта в HTML, preload hint LCP-картинки — на ~612 байте. Для EN-посетителей:
1. Браузер начинает парсинг
2. На строке 4 выполняется `location.replace('/en/')` 
3. Весь preload cache сбрасывается
4. Страница загружается с нуля из `/en/` URL

Это добавляет **+300–600ms к LCP для ~50% трафика**.

**Фикс:** переместить lang-redirect после preload hints, или использовать серверные redirects через Vercel rewrite.

### MEDIUM: Tours page render-blocking CSS
```html
<link rel="stylesheet" href="/fonts/lora.css"></head>
```
Синхронный stylesheet в конце `<head>` блокирует рендеринг. Homepage использует async preload trick — tours page должна делать то же.

### LOW: CLS риски
- Homepage: LOW — все изображения имеют width/height, font-display: swap, transform-based animations
- Tours: MEDIUM — font swap Lora→Georgia может вызвать layout shift
- Cookie bar: использует transform (не layout), не влияет на CLS

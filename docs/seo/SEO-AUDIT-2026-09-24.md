# 4. Дорожная карта

## Фаза 0 — зафиксировать состояние

**Без этого любая дальнейшая правка необратима.**

1. Закоммитить 958 файлов в ветку, запушить.
2. Перенести мусор из корня в `_archive/`: бэкапы `index.html.*`, `preview-*.html`, `hero3d-*.html`, `capture_*.py`, `audit_*.py`, логи.
3. Закрыть утечки — правило в `vercel.json`, отдающее 404 на `*.md`, `*.csv`, `seo-baseline-*`, `_baseline_*`, `skills-lock.json`, `/airtable-dump/`.
4. Снять базовый замер позиций: `python3 scripts/yandex-rank.py --targets scripts/rank-targets.csv`

**Результат:** есть точка отката и точка отсчёта.

## Фаза 1 — расшить каннибализацию

Главный рычаг. Даёт больше, чем всё остальное вместе.

**Схема на каждую пару «статья ↔ тур»:**

- В начало статьи, после первого абзаца (не в конец) — блок с ценой и кнопкой брони конкретного тура.
- Ссылка из статьи на тур с анкором = целевой коммерческий запрос («экскурсия в Казбеги из Тбилиси»), а не «читать подробнее».
- Обратная ссылка со страницы тура на статью как на справочный материал.
- Из title и H1 статьи убрать транзакционные слова, оставив их странице тура. Статья отвечает на «что это», тур — на «сколько стоит и как поехать».

**Порядок работ:**

1. **EN-версия, оптом** — 219 пар. Начать с narikala, tbilisi to kazbegi, tbilisi to batumi, truso valley, kakheti, ureki, david gareja. Это 500–3 400 показов на пару.
2. **RU/Яндекс, точечно** — 8–10 пар. Первая и главная: **казбеги** (первые два места в Яндексе у блога, тур третий; в Google блог 8.1, тур 55). Затем абанотубани, уреки, батуми, давид гареджи, чёрное море.
3. **Не трогать** вардзию и кахетию — там Яндекс уже ставит тур выше блога, можно сломать.

**Ожидаемый эффект:** коммерческие страницы поднимаются с 40–85 мест, доля коммерческого трафика растёт с 7% к 20–25%.

## Фаза 2 — гид-кластер

1. Снять редирект с `/gid/` и `/gid-v-tbilisi-na-russkom/`.
2. Создать `/gid/` — коммерческая страница услуги. Каркас `gid/_template` уже в репозитории. Структура:
   - H1 с точным ключом, цена **от ₾175 первым экраном** (единственное, чего нет в сниппетах агрегаторов)
   - блок отличий от Sputnik8/Tripster: без комиссии, прямой контакт с гидом, маршрут под запрос
   - 6–8 отзывов с именами и датами — Google Places API уже подключён
   - schema `Person` + `Service` + `AggregateRating` + `FAQPage`
   - форма и WhatsApp выше сгиба
3. Остальные четыре URL гид-кластера — 301 на `/gid/`, а не на `/about/`.
4. Переиндексация: `node scripts/indexnow-ping.js /gid/` + `python3 scripts/_reindex_batch.py`.
5. Контроль через 2 и 4 недели: `python3 scripts/yandex-rank.py --query "гид в тбилиси" --region 10277`

## Фаза 3 — гигиена ссылок

1. Автозаменой переписать 134 внутренние ссылки на конечные URL.
2. Починить `/sitemap.xml/` — 10 вхождений, баг `trailingSlash`.

## Фаза 6 — монетизация инфо-трафика

`[GSC]` 47% трафика приходит **из Грузии** — люди уже в стране. Это не «мёртвая аудитория», это лучший сегмент, до которого не доходит оффер.

**Решение — гео-сегментация через `middleware.js`** (91 строка, гео-логики сейчас нет). Vercel отдаёт заголовок `x-vercel-ip-country`:

```js
const country = req.headers.get('x-vercel-ip-country') || '';
res.headers.set('x-visitor-geo', country === 'GE' ? 'ge' : 'out');
```

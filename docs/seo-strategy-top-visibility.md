# SEO-стратегия Sakhva Travel: топ и видимость 85–90%

_Составлено 08.07.2026. Основано на полном техническом аудите 446 страниц + данных Яндекс.Вебмастера (500 запросов)._

---

## 1. Цель и метрика

**Цель:** видимость сайта в Яндексе 85–90% (сейчас ~70%), топ-3 по коммерческому ядру.

**Метрика видимости** (Вебмастер) = доля запросов ядра, стоящих в топ-10, взвешенная по позиции.
Растёт двумя способами:
- **(A) поднять существующие страницы** выше (позиция 5 → 2);
- **(B) занять запросы, где страниц ещё нет** (новый охват).

Не путать со «99%»: это недостижимо на ВЧ-коммерции — см. §7.

## 3. Модель: почему не в топ-1-2 при идеальном on-page

Ранжирование Яндекса = **релевантность (✓ готово) + поведенческие + коммерческие факторы + траст/ссылки/возраст**.

Раз релевантность максимальна, разрыв «поз. 3–8 → топ-3» закрывают оставшиеся 3 множителя. На запросах «туры в грузию из \{город\}» в топ-1-2 структурно сидят агрегаторы (Level.Travel, Тонкости туризма, Onlinetours) — их не обгонит текст, только поведение + охват + время.

## 4. Четыре рычага (по силе влияния)

### Рычаг 1 — Поведенческие (ПФ). Зона: Владимир. Скорость: быстро.
Фундамент вылизан → ПФ конвертируется в позиции без штрафов. Лить точечно, по приоритету потенциала:

| Приоритет | Цель ПФ | Сейчас | Потенциал |
|---|---|---|---|
| 1 | «экскурсия боржоми из тбилиси» | 3.7 / 638 показов / 124 клика | 1 шаг до топ-3, максимальный ROI |
| 2 | 21× `tury-v-gruziyu-iz-*` | поз. 3–8 | топ-3 всего кластера |
| 3 | Казбеги / Кахетия экскурсии | топ-1-2 | удержание |

### Рычаг 2 — Расширение охвата. Зона: агент. Скорость: средняя. Прирост: чистый.
Запросы с реальными показами, где страниц НЕТ или позиция слабая — создать/усилить:

| Запрос | Поз. | Показы | Действие |
|---|---|---|---|
| экскурсия из сочи в батуми | 12.7 | 64 | **новая страница** (трансфер/тур Сочи→Батуми через Верхний Ларс) |
| экскурсии из сочи в грузию | 12.2 | 52 | покрыть на той же/связанной странице |
| тур в грузию из нальчика | 11.9 | 56 | усилить существующую |
| тур в грузию гори | 11.2 | 49 | проверить страницу Гори |
| туры из кисловодска в грузию | 9.1 | 53 | усилить |
| экскурсионные туры в грузию 2026 | 9.3 | 46 | усилить хаб |
| + длинный хвост со 2-й страницы | 7–10 | — | добор пачкой |

### Рычаг 3 — Коммерческие факторы Яндекса. Зона: агент. Скорость: средняя.
Отдельный фактор (не ПФ, не ссылки): онлайн-цены на каждый тур, видимые контакты/мессенджеры, способы оплаты, отзывы, полнота карточки компании. На кластере есть — довести до максимума и распространить на все коммерческие лендинги. +0.5–1 позиции без переспама.

### Рычаг 4 — Траст / возраст / упоминания. Зона: фон. Скорость: медленно.
То, что структурно отделяет от агрегаторов. Не педалируем ссылочное — работаем органикой: карточки в Я.Бизнес/Картах, отзывы, брендовые упоминания. Долгий фон, не быстрый рычаг.

## 5. Дорожная карта

**Фаза 1 (неделя 1) — добор нулевого охвата.**
Агент: страница Сочи→Батуми/Грузия (2 запроса, 116 показов, 0 покрытия). Владимир: ПФ на боржоми (№1 по ROI).

**Фаза 2 (недели 2–3) — усиление слабых коммерческих.**
Агент: усилить Нальчик, Кисловодск, Гори, хаб «экскурсионные туры» под их точные интенты. Владимир: ПФ на кластер городов.

**Фаза 3 (недели 3–4) — коммерческие факторы + длинный хвост.**
Агент: догнать коммерческие факторы по всем лендингам, собрать хвост со 2-й страницы. Контроль заспама после каждой правки.

**Фаза 4 (постоянно) — мониторинг + траст-фон.**
Еженедельный съём позиций Вебмастера, Я.Бизнес/отзывы, реакция на просадки.

## 6. Контроль качества (переспам недопустим)

- Перед/после каждой контентной правки — замер `words_spam` через Pixel Tools textanalyser. Норма гео/коммерц < 75.
- Рост только через **уникальность и полноту интента**, не через плотность ключа.
- Диверсификация анкоров перелинковки (уже сделано на главной).
- Каждую новую страницу проверять на near-dup к кластеру (порог < 30%).

## 7. Реалистичный потолок

| Тип запроса | Потолок для сайта-гида |
|---|---|
| ВЧ-коммерция «туры в грузию из города» | топ 3–5 (топ-1-2 держат агрегаторы) |
| Транзакционные «экскурсия \{направление\} из тбилиси цена» | **топ-1-3 — уже держим, это хлеб** |
| Инфо длинный хвост (блог) | топ-1-3 |
| Общая видимость сайта | **85–90% достижимо** (A: ПФ дожимает + B: охват) |

**Формула итога:** идеальный on-page (есть) × ПФ на приоритет (Владимир) × расширение охвата (агент) × коммерческие факторы (агент) = видимость 85–90% + топ-3 по транзакционному ядру.

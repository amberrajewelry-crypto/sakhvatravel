## Формулы и пороговые значения

### Unit-экономика

| Параметр | Формула | Значение |
|----------|---------|----------|
| Средний чек (взвешенный) | -- | $130 |
| Маржа Владимира | 60% - 3% платёжка | 57% = $74 |
| Breakeven CPC | чек x маржа x CR(site-to-sale) | $130 x 0.57 x 1.3% = $0.96 |
| Target CPC (ROAS 300%) | Breakeven / 3 | $0.32 |
| Реальный средний CPC | -- | ~$0.63 |
| Breakeven CR(site-to-WA) | CPC / (чек x маржа x CR(WA-to-sale)) | $0.63 / ($130 x 0.57 x 0.22) = 3.9% |
| CAC (при CR 1.3%) | CPC / CR(site-to-sale) | $0.63 / 0.013 = $48.5 |
| LTV (1 тур) | -- | $74 |
| Profit per customer | LTV - CAC | $25.5 |

### Красные флаги

| Метрика | Порог | Действие |
|---------|-------|----------|
| CTR < 1.5% | За 3 дня | Переписать объявления или пауза ключа |
| CPC > $0.80 | Разовый | Снизить ставку или пауза ключа |
| CR(site-to-WA) < 2% | За 7 дней | Проверить лендинг, позицию CTA |
| Quality Score < 5 | -- | Улучшить релевантность объявления к ключу |
| Bounce Rate > 70% | За 7 дней | Проблема с лендингом или нерелевантный трафик |
| Impression Share < 30% | За 7 дней | Повысить ставку или бюджет |

## День 1-3: Запуск и модерация

### Задачи
1. **Проверить одобрение объявлений** (Google Ads > Ads > Status)
   - "Eligible" / "Approved" -- ок
   - "Under review" -- ждать до 48ч
   - "Disapproved" -- прочитать причину, исправить, переотправить
   
2. **Проверить показ** (Google Ads > Overview)
   - Если 0 показов через 24ч: проверить ставки, расписание, геотаргетинг
   - Если показы есть но 0 кликов: CTR проблема, переписать заголовки

3. **Базовые метрики за первые 72ч**
   - Целевой CTR: >2%
   - Целевой CPC: <$0.80
   - Показы: >100/день (если меньше -- расширить ключи)

### Чеклист дня 3
- [ ] Все объявления одобрены
- [ ] CTR > 2% по каждой группе
- [ ] CPC < $0.80 по каждому ключу
- [ ] Нет отклонённых объявлений
- [ ] WA-клик трекинг работает (хотя бы 1 конверсия)

---

## День 3: Первая чистка

### Действия
1. **Отключить ключи с CTR <1%** за 3 дня
   - Google Ads > Keywords > Sort by CTR > Pause low performers
   
2. **Отключить ключи с CPC >$0.80**
   - Или снизить Max CPC до $0.60

3. **Проверить Search Terms Report**
   - Google Ads > Keywords > Search terms
   - Добавить нерелевантные запросы в минус-слова
   - Найти новые релевантные запросы для добавления

4. **Проверить Quality Score**
   - Google Ads > Keywords > Columns > Modify > Quality Score
   - Ключи с QS <5 -- улучшить релевантность (заголовок = ключ)

## День 7: Первая оптимизация

### Анализ Search Terms (КРИТИЧНО)

1. Открыть Google Ads > Keywords > Search terms
2. Выгрузить за 7 дней
3. Разделить на категории:

| Категория | Действие |
|-----------|----------|
| Релевантные с конверсией | Добавить как exact match |
| Релевантные без конверсии | Оставить, наблюдать |
| Нерелевантные | Добавить в минус-слова |
| Конкуренты (tripster, viator) | Решить: конкурировать или минусовать |

### Оптимизация ставок

| Ситуация | Действие |
|----------|----------|
| Ключ: CTR >5%, CPC <$0.50 | Повысить ставку на 15% |
| Ключ: CTR 2-5%, CPC $0.50-0.80 | Оставить |
| Ключ: CTR <2%, CPC >$0.60 | Снизить ставку на 20% |
| Ключ: 0 конверсий за 50 кликов | Пауза |

### Оптимизация объявлений

- Проверить какие заголовки показываются чаще (Ad assets > View asset details)
- Заменить заголовки с низким Impression share
- Если один RSA сильно лучше другого -- написать третий на основе лучшего

## День 14: Переход на Maximize Conversions

### Условие перехода
- Накоплено 15+ конверсий (WA-клик) за последние 30 дней
- Конверсии стабильны (не все в один день)

### Если 15+ конверсий ЕСТЬ:
1. Google Ads > Campaign > Settings > Bidding
2. Сменить "Maximize Clicks" на "Maximize Conversions"
3. НЕ ставить Target CPA сразу -- дать алгоритму обучиться 7 дней
4. Наблюдать за CPC -- может вырасти в первые 3-5 дней (обучение)

### Если 15+ конверсий НЕТ:
- Остаться на Maximize Clicks ещё 14 дней
- Проверить воронку: показы → клики → WA-клики
- Возможные причины нехватки конверсий:
  - Лендинг не конвертит (CTA не виден, долгая загрузка)
  - Трекинг сломан (проверить Tag Assistant)
  - Нерелевантный трафик (проверить Search Terms)

## День 30: Target ROAS

### Условие
- 30+ конверсий за последние 30 дней
- Стабильная стоимость конверсии (отклонение <30% от средней)

### Переход на Target ROAS 400%
1. Google Ads > Campaign > Settings > Bidding
2. Сменить на "Target ROAS"
3. Установить Target ROAS: 400%
4. Это значит: на каждый $1 расхода алгоритм целится в $4 выручки

### Расчёт Target ROAS

| Параметр | Значение |
|----------|----------|
| Средний чек | $130 |
| Target CPA (для прибыльности) | <$74 (маржа) |
| Breakeven ROAS | $130 / $74 = 176% |
| Target ROAS (для прибыли) | 400% |
| Это значит CPA | $130 / 4 = $32.5 |
| Прибыль при ROAS 400% | $74 - $32.5 = $41.5/заказ |

### Если 30 конверсий НЕТ
- Остаться на Maximize Conversions
- Проанализировать почему мало конверсий
- Рассмотреть расширение бюджета до $30/день
- Рассмотреть добавление EN-кампании для англоязычных туристов

## Масштабирование (после 30 дней)

### При ROAS >300%:
1. Увеличить бюджет на 20% каждые 7 дней (не более!)
2. Добавить EN-кампанию (англоязычные туристы)
3. Добавить ремаркетинг (посетители сайта, не заказавшие)
4. Тестировать Performance Max с фидом экскурсий

### При ROAS 150-300%:
1. Не увеличивать бюджет
2. Фокус на оптимизации: Quality Score, лендинги, объявления
3. A/B тест лендингов (разные CTA, фото, отзывы)

### При ROAS <150%:
1. Сократить до 3 лучших Ad Groups
2. Только exact match ключи
3. Снизить бюджет до $10/день
4. Если ROAS <100% за 14 дней -- пауза кампании, пересмотр стратегии

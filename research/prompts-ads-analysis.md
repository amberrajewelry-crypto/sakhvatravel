# Промпты для анализа Google Ads — Sakhva Travel

## 1. Ежедневный анализ (каждый день после 09:00)

```
Проанализируй Google Ads за вчера. Данные в Google Sheets [ВСТАВЬ URL ТАБЛИЦЫ].

Посмотри листы Campaign_Daily, AdGroup_Daily, Keywords_Daily, SearchTerms_Daily.

Дай:
1. Расход, клики, CTR, CPC по каждой группе
2. Какие ключи работают, какие сливают бюджет (клики без конверсий)
3. Search Terms — какие реальные запросы пришли, что добавить в негативы
4. Конкретные действия: что отключить, что усилить, какие негативы добавить
5. Сравни с вчерашним днём — тренд лучше/хуже

Бюджет $15/день. Цель — заявки на туры через WhatsApp и форму.
```

## 2. Еженедельный глубокий анализ (воскресенье)

```
Еженедельный анализ Google Ads Sakhva Travel. Данные в Google Sheets [ВСТАВЬ URL ТАБЛИЦЫ].

Проанализируй все 4 листа за последние 7 дней:

1. БЮДЖЕТ: общий расход, CPA (если есть конверсии), ROI по группам
2. ГРУППЫ: какая группа лучше работает (Kakheti_Vino / Gid_Tbilisi / Chastniy_Tur)
3. КЛЮЧИ: топ-5 по кликам, топ-5 по конверсиям, ключи с расходом >$2 без конверсий — кандидаты на паузу
4. SEARCH TERMS: паттерны запросов, новые негативы, идеи для новых ключей
5. QUALITY SCORE: ключи с QS < 5 — что улучшить
6. IMPRESSION SHARE: сколько показов теряем, из-за бюджета или ранга
7. РЕКОМЕНДАЦИИ: конкретный план на следующую неделю (ставки, ключи, негативы, тексты)

Бюджет $15/день ($105/нед). Цель — максимум заявок на туры.
```

## 3. Экстренный (если подозрение на слив)

```
Срочно проверь Google Ads. Кажется бюджет сливается.
Данные в [ВСТАВЬ URL ТАБЛИЦЫ].

Найди:
- Ключи с >3 кликами и 0 конверсий
- Search terms нерелевантные (не про туры/гид/экскурсии)
- CTR ниже 3% — почему
- Дай список негативов для немедленного добавления
```

## Как пользоваться

1. Скрипт в Google Ads пишет данные каждый день в 08:00
2. После 09:00 вставь ежедневный промпт в чат
3. По воскресеньям — еженедельный
4. Если видишь странный расход в Google Ads — экстренный

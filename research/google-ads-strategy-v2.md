# 1. СТРУКТУРА АККАУНТА

## Рекомендуемые кампании

| # | Кампания | Тип | Бюджет % | Обоснование |
|---|---------|-----|----------|-------------|
| 1 | Sakhva_Search_Flagships | Search | 50% | Горячий интент: Казбеги, Кахетия, Мцхета — 80% дохода |
| 2 | Sakhva_Search_Guide | Search | 20% | "гид тбилиси", "экскурсовод" — люди ищут человека, не тур |
| 3 | Sakhva_Search_General | Search | 15% | "туры грузия", "экскурсии тбилиси" — широкий захват |
| 4 | Sakhva_Search_Competitors | Search | 10% | Брендовые запросы Tripster, Viator, Sputnik8 |
| 5 | Sakhva_Remarketing | Display | 5% | Ретаргетинг посетителей сайта (после 50+ конв/мес) |

**Почему НЕ PMax на старте:** Нет истории конверсий. PMax требует 30+ конверсий/мес для обучения. Запускаем после 2 месяцев Search.

**Почему НЕ YouTube:** Бюджет до $3000/мес слишком мал для видео в travel. YouTube добавляем при $5000+/мес.

## Логика Ad Groups

**По турам (не по интентам).** Причина: каждый тур имеет свой лендинг, свою цену, свою маржу. Это позволяет:
- Управлять CPC отдельно на каждый тур
- Писать релевантные заголовки с конкретной ценой
- Считать ROAS по каждому туру

# 8. TRACKING & REMARKETING

## UTM Tracking Template (установить на уровне аккаунта)

```
{lpurl}?utm_source=google&utm_medium=cpc&utm_campaign={_campaign}&utm_content={adgroupid}&utm_term={keyword}
```

## RLSA (Remarketing Lists for Search Ads)

Когда аудитория ремаркетинга достигнет 1000 юзеров:
1. Создать аудиторию "All visitors" (30 дней)
2. Создать аудиторию "Tour page visitors" (90 дней)
3. Добавить в каждую кампанию как Observation
4. Bid modifier: +50% для "Tour page visitors"

## Image Extensions

Загрузить в Google Ads → Extensions → Image:
- Казбеги: hero-фото Гергети на фоне гор (1200×628)
- Кахетия: квеври-вино + виноградники (1200×628)
- Мцхета: Светицховели (1200×628)
- Гид: фото Тимура с группой (1200×628)

Эффект: +15% CTR в мобильной выдаче.

## Cross-Campaign Negatives (уже в CSV)

Логика разделения трафика:
- **Flagships** ← все запросы с названием тура (казбеги, кахетия, мцхета)
- **Guide** ← запросы "гид" без названия тура
- **General** ← широкие запросы ("экскурсии из тбилиси") без тура и без "гид"
- **Competitors** ← брендовые запросы конкурентов без названия тура

Негативы:
- General: [exact] казбеги, кахетия, мцхета, гид тбилиси, частный гид
- Guide: [broad] казбеги, кахетия, мцхета, сигнаги, гергети, ананури, винный тур
- Competitors: [exact] казбеги, кахетия, мцхета, гид тбилиси

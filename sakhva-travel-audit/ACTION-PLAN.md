# Sakhva Travel — план вывода КОММЕРЦИИ в топ Google

_Аудит 08.08.2026. 6 SEO-специалистов + данные GSC (90 дней). Артефакты: findings/_

## Диагноз (одной строкой)
RU-карточки экскурсий сгенерированы по шаблону (слабая уникальность, без отзывов), голодают по внутренним ссылкам и перебиваются блогом → поз. 25–48. EN-карточки писались вручную, с отзывами → поз. 5–15. **Playbook: сделать RU-карточки такими же, как EN + перелить вес блога + забрать коммерч-запросы у блога.**

## Что НЕ проблема (проверено)
- Индексация, robots, noindex — чисто.
- Схема TouristTrip/Product/Offer/Breadcrumb/FAQ — есть на всех 213 карточках.
- CWV — зелёные (PSI 97–99).
- Карточки не тонкие по объёму.
- ЛОЖНО (агент ошибся, верифицировано): kakheti НЕ сирота — есть в sitemap (15×) и в хабе.

## Находка 1 — Near-duplicate «Практические советы» (CRITICAL)

**Severity: HIGH**

45 из 71 RU-карточек содержат идентичный блок `<h2>Практические советы</h2>` + идентичный абзац «Перед тем как отправиться в [топоним], убедитесь...» с подстановкой топонима. Контент идентичен на уровне 80-90% между карточками: «удобная обувь», «солнцезащитный крем», «возьмите камеру», «лучшее время — весна и осень».

Это near-duplicate content в масштабе сайта — Google видит 45 страниц с одинаковыми секциями на коммерческих URL и снижает их авторитет относительно друг друга.

EN-карточки этого блока НЕ имеют — там тексты написаны заново под каждый маршрут.

**Фикс:** Удалить шаблонный блок «Практические советы» из карточек, где он generic. Заменить маршрутно-специфическим: для Боржоми — про воду из источника и кальканат, для Казбеги — про высоту и одышку (там уже есть, это пример как надо), для Кахетии — про дегустацию за рулём.

## Находка 2 — В RU-карточках нет живых отзывов (HIGH)

**Severity: HIGH**

EN-карточка Gomis Mta (поз. 5.7) содержит блок `#reviews` с 6 цитатами от реальных людей (имя, платформа, дата, звезды, текст). RU-карточки — либо пустая секция `#reviews`, либо её нет совсем. Карточка Кахетии (поз. 38) — отзывов в HTML нет вообще.

Google Sept 2025 QRG: отзывы с именами, датами и платформой — прямой E-E-A-T сигнал для коммерческой страницы. Их отсутствие в RU — одно из объяснений поз. 25-48 vs EN 5-15.

**Фикс:** Добавить в каждую RU-карточку минимум 3 отзыва (имя, дата, платформа — Google/Яндекс, текст 2-3 предложения). Можно взять из GBP (там 106 отзывов по данным CLAUDE.md). Review schema (`aggregateRating` в Product JSON-LD уже есть, но без отображаемых отзывов Google это «неподтверждённый рейтинг»).

## Находка 3 — Каннибализация блог vs карточка Кахетии (MEDIUM)

**Severity: MEDIUM**

`/blog/kakheti-za-1-den/` (поз. 35) и `/ekskursiya/ekskursiya-kakheti-iz-tbilisi/` (поз. 38) частично пересекаются по контенту:

- Оба содержат маршрут по точкам (Сигнаги, Бодбе, марани)
- Оба описывают дегустацию вин с конкретными сортами
- Оба дают практические советы

Разница есть, но слабая: карточка имеет цену, форму бронирования, программу по часам. Блог имеет таблицу расстояний, раздел «какое вино купить», секцию самостоятельного доехать.

При коммерческом запросе «экскурсия в кахетию из тбилиси» Google не уверен, какую страницу показывать — они слишком похожи по содержанию.

**Фикс:** Развести интенты жёстче:
- Карточка: убрать из неё раздел «как добраться самостоятельно» и «что посмотреть» (это инфо-интент), оставить ТОЛЬКО коммерч: цена, бронь, программа по часам, включено/не включено, отзывы.
- Блог: убрать CTA-бокс с ценой (или сделать его сайдбаром, не основным контентом). Добавить чёткий disclaimer «хотите с гидом — →» одной ссылкой.
- Карточка должна однозначно кричать «купить тур», блог — «узнать про Кахетию».

## Находка 4 — Отношение уникальный текст / boilerplate в RU-карточках (MEDIUM)

**Severity: MEDIUM**

Структура RU-карточки (~86 КБ Кахетия):

| Блок | Уникальность | Объём |
|------|-------------|-------|
| Head/nav/CSS/JS | 0% (идентичен на всех) | ~40% файла |
| Hero + price box | ~90% (цена, время, маршрут уникальны) | ~5% |
| Программа по часам | ~95% (уникальна для каждого маршрута) | ~8% |
| Google Maps JS | ~70% (координаты разные) | ~10% |
| article-body основной | ~80% уникален (лучшие карточки) | ~10% |
| «Подробный маршрут» (второй) | **~30%** — часто дублирует программу по часам | ~8% |
| «Практические советы» | **~10%** — generic шаблон | ~5% |
| FAQ | ~85% уникален | ~5% |
| Includes/not-includes | ~80% | ~3% |
| Отзывы | 0% (пусто) | — |
| Footer | 0% | ~6% |

Проблема: карточки Борджоми, Кахетия, Ананури содержат два блока маршрута — «Программа по часам» (хорошая) + «Подробный маршрут и что смотреть» (generic, AI-сгенерированный стиль без конкретики). Это раздувает объём, но не добавляет ценности.

Для сравнения, EN-карточка Gomis Mta: нет generic «советов», нет дублирующего «Подробного маршрута», зато есть конкретные отзывы и хорошо структурированный «Timur's tip».

**Фикс:** Удалить «Подробный маршрут и что смотреть» там, где он дублирует «Программу по часам». Вместо него — добавить блок с реальными отзывами (см. Находку 2) или уникальный инсайт гида.

## Находка 5 — Тур-хабы: не пустышки, но слабые (LOW-MEDIUM)

**Severity: LOW-MEDIUM**

Проверены: `/avtorskie-tury-gruzia/`, `/grupovye-tury-v-gruziyu/`, `/individualnyy-tur-v-gruziyu/`, `/mnogodnevnye-tury-gruzia/`, `/gornye-tury-gruzia/`.

Хабы НЕ пустышки: есть FAQ schema, таблицы туров с ценами, перелинковка на карточки. `/avtorskie-tury-gruzia/` — полноценная страница с 87 отзывами в stats, FAQ 8 вопросов, уникальным позиционированием.

Слабые места:
1. `/grupovye-tury-v-gruziyu/` (650 строк HTML) — только таблица туров + базовый текст. Нет уникального контента про групповой формат (чем он отличается, как формируется группа, что входит в корп. тур).
2. `/individualnyy-tur-v-gruziyu/` — аналогично, структурная страница без real content.
3. Хабы не связаны между собой перелинковкой (нет «похожих форматов»).

**Фикс:** Не переписывать все хабы — это не приоритет vs карточки. Добавить 1-2 абзаца уникального контента на слабые хабы (чем групповой тур отличается от индивидуального конкретно у Тимура) + перелинковку хаб→хаб.

## Находка 6 — RU vs EN: почему EN ранжирует лучше (сводка)

**Severity: INFO**

Прямое сравнение Кахетия RU (поз. 38) vs Gomis Mta EN (поз. 5.7):

| Элемент | RU Кахетия | EN Gomis Mta |
|---------|-----------|--------------|
| Отзывы на странице | Нет | 6 отзывов с именами/датами |
| Generic «советы» | Да (шаблонный блок) | Нет |
| Дублирующий маршрут | Да | Нет |
| «Совет от гида» | Да (Борджоми/Казбеги) | Да |
| Инсайд-информация | Частично | Да (пик-ап из Кобулети/Чакви, тучи к полудню) |
| Мобильный WA link | Конкретный текст WA (`?text=Хочу+забронировать`) | Да |
| Review schema markup | aggregateRating без тела | aggregateRating без тела |

EN-карточки компактнее и чище — меньше boilerplate, больше конкретики на человека. Это не объём файла (оба ~70-90 КБ), а соотношение ценного контента к шаблонному.

## Топ-5 приоритетов для роста RU-карточек

1. **Добавить отзывы в RU-карточки** (минимум 3 на карточку из GBP/Яндекс.Карт) — наибольший E-E-A-T разрыв с EN.
2. **Удалить/переписать generic «Практические советы»** в 45 карточках — near-duplicate сигнал в масштабе домена.
3. **Убрать дублирующий «Подробный маршрут»** там где он следует за «Программой по часам» — чистый боилерплейт.
4. **Развести интенты карточка Кахетии vs блог** — убрать из карточки инфо-контент, сделать её чисто коммерческой.
5. **Добавить конкретный «Совет от Тимура»** (как в Казбеги и Боржоми — хорошие примеры) в оставшиеся карточки без него — это живой Experience-сигнал.
